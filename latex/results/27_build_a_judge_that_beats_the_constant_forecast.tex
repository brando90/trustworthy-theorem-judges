\subsection*{Bottom line}
No judge works under the pre-registered bar, but the frozen judge is close. On the 20 held-out test tasks (70 artifacts) it beats
the set-aware constant forecast on all three proper scores by point estimate (RPS 0.075 vs 0.110, CE 0.97 vs 1.19, TVD 0.35 vs 0.48),
and its paired RPS gain over the earlier H2 judge is clearly below zero ($-0.025$, 95\% interval $-0.049$ to $-0.005$). The paired RPS gain
over the constant is $-0.035$ with interval $[-0.076, +0.002]$, which includes zero by 0.002, so the verdict is \emph{promising}, not \emph{works}.
The evidence is small: 20 test tasks, 2 to 4 ratings per artifact, 73\% of the new ratings are 5s.

\subsection*{Reading}
\begin{enumerate}
  \item The CE-fitted calibration did what it was built for: the raw H2 judge has the lowest TVD but a poor CE (4.12) because its histograms are too sharp; calibration cuts CE to 0.97 and RPS from 0.100 to 0.075.
  \item On the new set the judge beats the set-aware constant on all three scores with intervals below zero (10 tasks); on the old set the point estimates are better but the RPS and CE intervals include zero (the TVD interval excludes zero).
  \item The new prompt's added value is not separated from calibrated H2: the H2-means-only candidate had validation RPS 0.062 vs 0.056 for the frozen one, on 35 artifacts.
\end{enumerate}

\subsection*{Caveats}
\begin{itemize}
  \item 20 test tasks, 70 artifacts, 2 to 4 ratings each, so the human distribution itself is noisy. Only 247 of 3,300 new rating rows were back; 73\% are 5s, so the new set is easy for a forecast that says ``5''.
  \item Selection among 125 candidates used 35 validation artifacts; the test set was scored once. The old test tasks were seen by the earlier judge in experiment 22 (not by this judge's fitting).
  \item No Lean check or differential testing. The H2 scores come from mixed harnesses. The F8 weights on the two H3 features are large and of opposite sign ($-6.0$ and $+6.1$ per standard deviation; near-collinear), so individual weights are not effects.
\end{itemize}

\subsection*{Appendix: methods, harness and model}
\begin{itemize}
  \item New-prompt (H3) judge calls: GPT-6 Astra, high reasoning, Codex CLI one-turn, read-only, no tools, Vals Codex plan; one call per artifact (105 train/validation, 70 test, all valid). H2 features cached: GPT-6 Astra and Claude Opus 5.5 (mixed harnesses across sets).
  \item Splits by task: old 10/5/10 (experiment 22 split); new 10/5/10 by seeded permutation (numpy default\_rng(20261124)). Pre-registration commit \texttt{152f3ec}; freeze commit \texttt{f3228ca} (before any test call). Correlation is never a fitting target.
  \item QA: Claude Opus 5.5 reproduced every pooled, old and new test number to 4 decimals; Grok grok-4.7 matched all 63 comparisons to 3 decimals; Cursor grok-4.7-high matched all 63 to three decimals (largest difference $2.66\times10^{-6}$). Not covered: the edit-distance baseline, raw-data provenance, whether H3 calls were repeated or cached.
  \item Record: \texttt{experiments/27\_*/RESULTS\_11-24-2026.md} on \texttt{main}.
\end{itemize}
