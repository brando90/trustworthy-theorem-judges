# Light QA of the interim re-run, by GPT-6 Astra (dated 11-24-2026)

**Who and how:** GPT-6 Astra through the Codex CLI on the Vals plan (router lane vals-codex, model gpt-6-astra), one turn, prompt in [qa_prompt_astra.md](qa_prompt_astra.md). Two tries: the first, asking Astra to run its code in its own sandbox, failed (the Codex sandbox could not start: "bwrap: loopback: Failed RTM_NEWADDR"), so Astra got no tools. The second asked Astra for a script only; it wrote [qa_recompute_astra.py](qa_recompute_astra.py) from the written definitions without seeing the pipeline code or any data. It ran first time on an anonymised copy of the per-artifact data (175 artifacts, 50 anonymised tasks, ratings and the three judge scores per judge; not committed, it holds individual ratings), run by the assistant on its own machine, not by Astra. Output: [qa_result_astra.json](qa_result_astra.json).

**Checked and matched the pipeline to 4 decimals (30 of 30 point values):** n, RPS, CE, TVD, Spearman, Pearson for each judge on old, new and pooled, and the set-aware constant RPS (old 0.1826, new 0.0698, pooled 0.1182) and pooled constant 0.1644. New-set RPS 95% task-bootstrap interval: Astra QA [0.031, 0.077] vs pipeline [0.031, 0.075]; Opus QA [0.029, 0.057] vs pipeline [0.029, 0.057] (different bootstrap draws, within 0.002).

**Differs, by definition:** split-half human RPS. Astra averaged both directions of the asymmetric RPS (old 0.139, new 0.061, pooled 0.095) vs the pipeline's single direction (0.128, 0.058, 0.088). It is not a headline number.

**Not checked:** the 10,000-draw intervals beyond the new-set one, set-aware difference intervals, the within-set Spearman, judge-minus-human bias, the learning curve, the Sheets reading (how raw rows became ratings), the raw judge call logs, and whether each human rating is right. Astra saw only the anonymised table, so it cannot catch an error in the table itself; the table was built by the same pipeline loader as the main run.
