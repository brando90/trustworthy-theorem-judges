# Main rating task: 100 files in 25 task folders

1. [Open your personal rating sheet](https://docs.google.com/spreadsheets/d/1zUDr9fpUwK0IuxrSdFfBR_mOt4WwMY8-doBC6cIhIHM/edit) for Brando Miranda.
2. Read [the scoring rubric](https://github.com/brando90/trustworthy-theorem-judges/blob/main/experiments/09_prepare_packets_and_collect_human_ratings_start_28Sep2026/rating_task_packet/human_judgements_prompt.md). Compare theorem statements, not proofs.
3. Follow the numbered task folders. In each, read `python_source/source.py`, the reference statements in `gold_lean/reference.lean`, and each file in `agent_lean/`.
4. In your sheet, for each file enter `final_score_0_5` (0 to 5) and answer `ai_assisted_rating_attestation` with yes, no or unsure to: "I used AI for localized assistance. I personally compared the specifications and chose the final score; I did not delegate the rating task to AI." If you rated a file without any AI, answer no and write "rated personally without AI" in `problem_note`. Please also estimate `minutes_spent` and `confidence` (low, medium or high). `rationale (optional)`, the last column, is welcome but optional.

Your sheet saves automatically; there is nothing to send back. Leave unfinished scores blank. If a reference looks wrong, leave its score blank, describe it in `problem_note` and email brandojazz@gmail.com.
