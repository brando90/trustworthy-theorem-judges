### How the native runs were made

- **Same inputs and limits.** Every run had the same input manifest (`e7a46a58…`), prompt version 8, a Docker image built on the same Lean image (`2104a4b8…`) and a 1,800-second wall clock per task. An egress proxy let each container reach only its vendor's hosts (Grok: `auth.x.ai`, `cli-chat-proxy.grok.com`, `grok.com`; Antigravity: `aicode.googleapis.com`, `daily-cloudcode-pa.googleapis.com`, `oauth2.googleapis.com`, `www.googleapis.com`); telemetry hosts were denied. Conditions: [Claude Code V3](../../research_artifacts/09_human_rating_collection/preparation_11-09-2026/native_harness_packet_11-11-2026/CC_CONDITION_VALID_V3.json), [Grok CLI V3](../../research_artifacts/09_human_rating_collection/preparation_11-09-2026/native_harness_packet_11-11-2026/GROK_CLI_CONDITION_V3.json), [Antigravity CLI V1](../../research_artifacts/09_human_rating_collection/preparation_11-09-2026/native_harness_packet_11-11-2026/ANTIGRAVITY_CONDITION_V1.json).
- **Brando's accounts, no API keys.** Claude Code ran on his Claude plans (the Vals plan paid for 1 of the 6 files, his personal plan for 5), Grok CLI on his grok.com account and Antigravity on his Google AI Ultra account.
- **Attempts, fixed before any output they govern** ([amendment](../../research_artifacts/09_human_rating_collection/preparation_11-09-2026/native_harness_packet_11-11-2026/NATIVE_ATTEMPTS_AMENDMENT_11-16-2026.json)). A task without a usable file gets up to 3 counted attempts under the identical condition, and the lowest-numbered usable attempt is used. Gemini used attempt 1 for 24 tasks and attempt 2 for 1. Grok used attempt 1 for 22 tasks and attempt 2 for 2; html_escape's first 3 attempts produced no file, attempts 4–6 were added before any of their output, and Brando approved using attempt 4 ("Yes, use it"). Claude Code: 10 runs cut off by a plan's billing limit (6 at 12:06 PM, 3 at 4:51 PM and 1 at 10:07 PM on 11-16-2026) are never counted and their files are never used; counting the rest, 4 tasks needed 1 attempt, base32 2 and edit_distance all 3 (its first 2 reached the wall clock without a file).
- **Run time.** Median minutes per task: Gemini 14.8 (range 3.4–30.1), Claude Code V3 23.2 (16.2–27.9), Grok 27.2 (12.2–31.1).
- **Run folders** (receipts, streams, session transcripts): `claude_code_valid_v3*`, `grok_cli_v3*` and `antigravity_cli_v1*` in [`native_harness_packet_11-11-2026/`](../../research_artifacts/09_human_rating_collection/preparation_11-09-2026/native_harness_packet_11-11-2026/).

**Confounding note:** harnesses differ by agent (each vendor's own tools and stopping rules), and Codex used prompt version 5 while the other three used 8, so cross-agent differences from this round are confounded with harness and prompt version; the collection supports human-rating data and held-out judge evaluation, not a harness ranking. **Isolation:** the earlier flag on 4 set N Terminus 2 files no longer applies, because those files are not in this packet. Item-to-agent keys stay in git-ignored `sealed/` while raters score. **Blinding exposure:** public Git history and the committed run folders show which agent wrote each file, so a rater who browses this repository could identify agents; rater emails do not link to the repository, and the analysis should record this possible exposure. Requested in the email: about 30 files a week, **the first 30 by Monday, 11-23-2026, 6 PM PT**.

Final score and the combined AI assistance/human-rating attestation (`yes`, `no`, or `unsure`; short unassisted files use `no` + `rated personally without AI` in `problem_note`) are required for new ratings. Time (`minutes_spent`) and `confidence` are requested; `problem_note` records issues; a one-sentence rationale in the last column, `rationale (optional)`, is **preferred but optional** (main forms since 11-17-2026; warm-up forms call it `rationale`). Delivered archives remain unchanged; raw CSVs preserve exact Sheet values and missingness, plus a last `source_label` column naming the round (`warm-up`, `main`, `historical_main`, `May`) so all rounds can sit and be filtered together. [Normalized analysis files](ratings/analysis/) are separate and are not additional observations.
