**TLDR:** The active folder list contains nine homes: judge methodology (02), human-rating preparation and collection (09), rating-data size estimates (15), persona raters from public information (20), the frontier-judge pool run (21), the 5-metric judge evaluation and methodology document (22), the gaming and file-format test of the evaluation pipelines on VeriBench VB256 (23), the pooled old-plus-new judge evaluation pre-registration (25), and the old-plus-new human-ratings analysis explaining `"0.6, 0.8, 0.8"` and expanding 5-metric evaluation to `cert-judge` (26).
