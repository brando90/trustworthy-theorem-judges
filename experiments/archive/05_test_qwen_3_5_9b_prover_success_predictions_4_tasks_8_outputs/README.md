# Test Qwen 3.5 9B prover-success predictions on four tasks and eight outputs

**Doc link:** <https://github.com/brando90/trustworthy-theorem-judges/blob/main/experiments/05_test_qwen_3_5_9b_prover_success_predictions_4_tasks_8_outputs/README.md>

**Companion notes:** [Google Doc](https://docs.google.com/document/d/1zB-gYk-zU1wToS_E_carGSRGtUcF1NgZ-jWF5t1SJws)

Status, 11-06-2026: both conditions are complete. The recovery produced three unsuccessful operational outcomes and five malformed artifacts; all parsed forecasts were zero. No judge was validated. This is a small pipeline feasibility experiment, not a validated replacement for the larger [experiment04 plan](../../04_test_prover_success_predictions_on_unseen_tasks/PLAN.md).

Four pinned Python tasks provide eight new statement-only artifacts, generated by two configurations of the installed Qwen3.5 9B model. Two separately identified judge configurations forecast a new local bounded prover condition. The event requires both a checked implication from candidate to every reference obligation and a checked consistency witness. Failed bounded search does not prove non-entailment. The predictor never receives outcome bits or proof certificates.

The local condition differs from VeriBench experiment169's blocked Pi/Gemini target. It uses no provider key and makes no paid inference call. Its task sources were previously exposed; its new outputs do not create a task-family-held-out test relative to experiment03. The four source contexts were selected for transparent, two-function interfaces. The original extraction population remains 14 emitted and 86 unresolved out of 100. No broad benchmark, natural-population, frontier, or unseen-model-family conclusion follows.

The local route is Ollama 0.40.8, `qwen3.5:9b-q4_K_M`, weight digest `56671c2ab9385f9cfcb404638e32cd62d88e3501d44822208363c010179a3c90`. Official documentation describes the [chat endpoint](https://docs.ollama.com/api/chat) and [thinking controls](https://docs.ollama.com/capabilities/thinking); this run pins the installed digest rather than a floating library alias. Thinking settings, combined output-token counts and thinking-character counts are retained per call; separate thinking-token counts are not exposed. Selection rationale: this installed, idle model provides a no-provider-cost feasibility route while the required hosted route is unavailable. There is no prior matched-domain judge-quality claim for it.

All raw prompts, source files, new statement artifacts, proof attempts and model responses remain under ignored `private/fresh_prover_target/`. Public reports contain hashes, protocol, opaque artifact rows and aggregates. Authorized source access is required to reproduce the source-context checks. No human ratings or sealed human data are used.
