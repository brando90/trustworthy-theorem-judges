# Experiment 27 results: a judge that beats the constant forecast on held-out tasks (Tue 11-24-2026)

**Bottom line:** I did not find a judge that works under the pre-registered bar, but the frozen judge is close: on the 20 held-out test tasks (70 artifacts) it beats the set-aware constant forecast on all three proper scores by point estimate (RPS 0.075 vs 0.110, CE 0.97 vs 1.19, TVD 0.35 vs 0.48), and its paired RPS gain over the earlier H2 judge is clearly below zero (-0.025, 95% CI -0.049 to -0.005). The paired RPS gain over the constant is -0.035 with 95% CI -0.076 to +0.002, which includes zero by 0.002, so the pre-registered verdict is **promising**, not **works**. The evidence is small: 20 test tasks, 2 to 4 ratings per artifact (mostly 2 to 3), and 73% of the new ratings are 5s. Not a trustworthy judge yet.

Date of run: Tue 11-24-2026. Pre-registration commit 152f3ec (before any run); freeze commit f3228ca (before any test call).

## Harness and model
- New prompt (H3) judge calls: GPT-6 Astra, high reasoning, Codex CLI one-turn, read-only, no tools, through Brando's Vals Codex plan (included usage). One call per artifact: 105 train/val, 70 test, all valid.
- H2 features (cached): GPT-6 Astra (old: OpenAI API; new: Codex CLI high), Claude Opus 5.5 (old: Vals gateway; new: Claude Code one-turn high). Mixed harnesses across sets, a known limit.
- Calibration, selection, bootstrap: CPU only (numpy/scipy, `scripts/`).
- QA: Claude Opus 5.5 (Stanford Claude lane, read-only Claude Code, it wrote the code) and Grok grok-4.7 (personal Grok lane, read-only, it wrote the code); I ran each model's script unchanged. See the QA section.

## Reading
1. The calibration did what it was built for: the raw H2 judge has the lowest TVD but a terrible CE (4.12) because its histograms are too sharp; CE-fitted calibration of the same scores cuts CE to 0.97 and RPS from 0.100 to 0.075.
2. On the new set the judge beats the set-aware constant on all three scores with intervals below zero (10 tasks). On the old set the point estimates are better but the intervals include zero for RPS and CE (TVD interval excludes zero).
3. The new prompt's added value is not separated from calibrated H2: the F3 (H2 means only) candidate was 0.062 on validation vs 0.056 for F8, a small difference on 35 artifacts.
4. Verdict under the pre-registration: **promising** (all three point estimates below the constant's and below H2's in RPS; the RPS interval against the constant includes 0 by 0.002). Pre-registered prediction was about 25% that "works" would be met.

## QA (Tue 11-24-2026; code written by the QA models from the anonymised input only, run unchanged by me)
- **Claude Opus 5.5** (Claude Code, Stanford Claude plan lane, heavy; read-only session, so it wrote the script and I ran it): every pooled, old and new test number above matches to 4 decimals (final judge 0.0751 / 0.9695 / 0.3549; constant per set 0.1100 / 1.1889 / 0.4787; H2 0.1002 / 4.1153 / 0.3310), the paired intervals match (RPS -0.0349 [-0.0760, +0.0024]; vs H2 -0.0252 [-0.0493, -0.0054]), and its own refit of the F8 calibration on train+val reproduces the test forecasts (max difference 2.8e-05). Leakage checks passed: no task in two splits or sets, no artifact without ratings, test forecasts sum to 1.
- **Grok grok-4.7** (Grok CLI, personal Grok lane, included usage; the Cursor grok-4.7-high request timed out twice and does not count): all 63 comparisons match to 3 decimals; its own refit matches (max difference 5e-06). Same leakage results. Rating counts: 85 artifacts with 2 ratings, 88 with 3, 2 with 4 (corrected above).
- Not covered by either QA: the edit-distance baseline, raw-data provenance, chronology of the freeze (checked by commit order: 152f3ec, f3228ca, then the test calls), whether the H3 model calls were repeated or cached.
- Observation from the QA refit: the F8 weights on the H3 score and the H3 expected score are large and of opposite sign (-6.0 and +6.1 per standard deviation), because the two features are almost collinear and no L2 penalty was selected. The fit is stable (three starts agree) but the individual weights should not be read as effects.

## Limits
- 20 test tasks, 70 artifacts; each has 2 to 4 expert ratings (35 test artifacts have 2, 34 have 3, 1 has 4), so the human distribution itself is noisy. Only 247 of 3,300 new rating rows are back; 73% are 5s, so the new set is easy for a forecast that says "5".
- Selection among 125 candidates used 35 validation artifacts; the test set was scored once.
- The old test tasks were seen by the earlier judge in exp 22 (not by this judge's fitting).
- No Lean check or differential testing is used; the H2 scores come from mixed harnesses.
- Set-aware constant is the bar: a judge that merely knows the set looks good against the pooled constant (0.171) and is not credited.
